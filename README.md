# 墨境 · 八方山河

水墨风横版探索游戏。默认的「山河漫游」是一张可以反复回访的连通世界：**8 个长区域、13 条双向地域连接、16 个实际可进入的隐藏空间、32 枚地域藏印、16 页暗室记忆、4 条跨地域角色支线、6 种持久能力及两种结局**。支持单人、本地双人、触屏独立多指操作。画面、音效由 Canvas / Web Audio 生成，无需账号、后端或网络素材。

## 世界与路线

| 地域 | 长度（游戏坐标） | 路线与故事 |
| --- | ---: | --- |
| 竹林初晴 | 13,000 | 林地与树冠、纸狐、旧井；照影灯取得后可回访暗门 |
| 云山问道 | 12,900 | 悬空群岛、风柱、浮舟；找到一封未送达的家书 |
| 月下听澜 | 13,150 | 可游月河、长途渡船、沿河灯台；回访摆渡人交信 |
| 丹霞古寺 | 14,500 | 阶梯、栈道、升降台、多座铜钟和守卫；回声让老僧说完旧事 |
| 不夜灯市 | 12,400 | 可交易的聚落、屋檐支路、归乡灯；修灯、补纸、寻找纸狐旧名 |
| 听泉溶洞 | 12,600 | 高低洞穴、水道和晶石顺序谜题；学会读出被擦掉的声音 |
| 霜岭归灯 | 13,200 | 有惯性的冰面、周期逆风、暖炉与雪屋；带灯回访守灯人 |
| 星河旧卷 | 14,600 | 低重力、日月翻页、记忆碑和最终守卫；七地复苏后选择最后一笔 |

原四关的地图长度扩展到原来的约 3–4 倍。地域之间通过实际路牌门双向连接，可以从竹林先去灯市，也可以从云山转往雪岭。打开山河图可查看真实连接，并回到已经抵达的地域营地；未到访地域不能直接快速旅行。

每个地域两处暗室。暗室有独立地形、昔今灯、记忆页、返回原入口的门；进出和重新读档后灯火、收藏和破坏状态仍保留。部分入口需取得照影灯、纸鸢、回声或暖墨后回来寻找。

## 不只收集的一段故事

画师不愿女儿远行，擦掉了通向山外的路。墨魇守着的不是宝藏，而是一个不肯面对离别的人留下的空白。

- **晚了三十年的家书**：完成云驿，回月河把信交给摆渡人。
- **阿砚真正的名字**：救出纸狐、找到三页记忆，再去灯市询问它。
- **石碑上的空白**：学会溶洞回声，再回古寺问老僧。
- **把灯带回雪里**：取得照影灯，再回访霜岭守灯人。

支线有对话选择、条件检查和实际奖励。最后可以保留一页空白，或为画卷打开一扇窗，两种选择分别强化滑翔或纸桥；结局后仍能探索，不清空进度。

## 玩法

- **山河漫游**（默认）：完整连通世界、角色交谈、资源、造桥、持久存档。失去所有生命时由纸鹤带回，损失少量铜钱，探索进度保留。
- **独立闯关**：直接选择任一长区域，进行独立挑战，不影响漫游存档。
- **双人竞速**：独立镜头，先抵达朱印者胜；机关进度共享。
- **墨潮追逐**：跑在墨浪前面完成区域。
- **寻印游记**：集齐该地全部 3–5 枚藏印再通关。
- **闲游山河**：连通世界的免伤版本，跌落不消耗生命，保留机关、故事及探索。

## 动作与能力

| 玩家 | 移动 | 跳跃 / 划水 | 踏墨 | 莲火 | 折纸造桥 | 下潜 / 交谈 / 进门 |
| --- | --- | --- | --- | --- | --- | --- |
| 朱红 | A / D | W / 空格 | E | F | Q | S |
| 青竹 | ← / → | ↑ | . | / | , | ↓ |

单人可用方向键。松开再按跳跃可二段跃，长按跳得更高。踏墨冷却 2.4 秒，可跨沟、破砖和破敌。莲火需要先取得红莲。

- **折纸桥**：漫游中在空中使用 Q / 造，花费一张纸铺出平台；每个空间最多四座。拾纸、营地免费补给、击败怪物和夜市交易可补纸；平台随空间存档保留。
- **御风纸鸢**：云驿复苏后学会，空中按住跳跃缓降。
- **莲步渡水**：月河任务奖励，不按下潜时可以踏水；按探仍可下潜。
- **照影灯**：夜市修灯或地域任务取得，显现旧地暗门。
- **回声读碑**：溶洞顺序谜题后学会，用于古寺支线与暗门。
- **暖墨护身**：减少雪岭逆风影响，打开冰封入口。

晶石需按「探」敲响，次序为月 → 山 → 水；错误可重试。翻页石附近按探切换日/月平台的真实碰撞。M / 图打开山河图，P / Esc 暂停。漫游中 R / 回营保留进度返回营地，挑战中 R 重开。

## 手机、平板与存档

- 点开始自动进入沉浸视图，右上角有地图、手记、暂停和返回；不用依赖浏览器全屏 API。
- 触控区位于画面外，移动、跳跃、踏墨、造桥、火球、探分开操作。支持按住方向时滑向相邻方向。
- 本地双人有独立镜头与各自按键，支持四指同时输入。推荐平板横屏，窄屏自动上下分屏。
- 大号键、长按连续跳、设备支持时的震动可在辅助设置切换。失焦、触点取消和旋转屏幕时清理输入。
- 漫游每三秒及关键操作时自动存入当前浏览器。不同浏览器/设备不自动同步；在山河图中「导出旅程」，到另一台设备「导入旅程」即可接续。导入失败会保留原进度。

## 开发、构建与离线试玩

Node.js 20.19+ 或 22.12+，已验证 Node.js 24。

```bash
npm ci --cache /tmp/mario-npm-cache --no-audit --no-fund
npm run dev -- --port 5173 --strictPort
npm test
npm run test:browser
npm run build:offline
```

`dist/` 是静态站点；**`dist/mario.html`** 是全部脚本、样式和图标内嵌的离线版。构建使用相对资源路径，支持部署在项目子路径。`npm run preview -- --port 4173` 可预览标准构建。

浏览器测试优先使用系统 Chromium，或设置 `CHROMIUM_PATH`。没有系统浏览器时运行 `npx playwright install chromium`。

自动验证覆盖八个长区域的通关与寻印路线、全部 16 个暗室的实际探索、区域图连通性、回访状态、保存/恢复、角色支线条件、造桥消耗、结局奖励，以及手机/平板多指、横竖屏、地图、真实地域切换、对话及导出。路线测试使用正常输入，不传送角色到目标、不增加生命。

## 发布手机可访问的网站

本地服务端口和工作区文件链接不等于公网网址。项目已附 `.github/workflows/pages.yml`，可在 GitHub Pages 发布：

1. 将项目改动提交并推送到 `main`。
2. 仓库 Settings → Pages → Source 选择 **GitHub Actions**。
3. Actions 中等待「Publish Ink Kingdom to GitHub Pages」成功；部署步骤输出的 Pages 地址才是可分享给手机的实际网址。

当前云环境访问 GitHub 发布 API 被网络规则阻止，尚未验证线上部署，也没有创建公网试玩地址。网络草稿已加入 `api.github.com`、`chipmonthly.github.io` 两个发布检查目标；保存并应用相关配置后需要重新检查 API 的实际权限，不应假定 Git 读取权限等同于 Pages 发布权限。也可以把 `dist/` 部署到已有静态托管平台。

## 源码

- `src/levels.js`、`src/expansions.js`：地域、延伸地形、实际连通门与暗室。
- `src/world.js`、`src/world-runtime.js`：世界存档、回访、人物、支线与能力。
- `src/engine.js`：物理、碰撞、水域、机关、怪物及守卫。
- `src/render.js`、`src/world-art.js`：程序化山水与场景物件。
- `src/main.js`：界面、地图、独立多触点控制与存档导入导出。
- `tests/traverse.js`：使用正常动作的路线模拟玩家。
- `scripts/standalone.mjs`：离线打包。

非官方同人作品，向经典横版游戏致敬。
